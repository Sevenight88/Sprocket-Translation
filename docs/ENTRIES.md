# 词条格式说明

本仓库**不含词条**（见 `README.md`）。你想汉化什么，就自己写一个 `.txt` 放进游戏的
`Translations\` 目录，重启游戏生效。规则全部来自 `Plugin.cs`，下面每条都能在那份源码里找到对应实现。

## 放在哪

插件按这个顺序加载，后加载的同键覆盖先加载的：

1. DLL 内嵌的加密词条 `entries.bin`（本仓库不发行，没有这层就是空表）；
2. `<游戏根>\Translations\**\*.txt`（递归子目录）；
3. `<游戏根>\BepInEx\Translations\**\*.txt`。

所以自定义词条推荐放 `<游戏根>\Translations\我的词条.txt`。文件编码 UTF-8（有无 BOM 都行）。
同一个键在多个文件里重复出现时，以哪份生效取决于枚举顺序，不要依赖它——自己维护时避免重复键。

## 一行一条：`原文=译文`

- 分隔符是**第一个不在 `<...>` 富文本标签里的** `=`。这样 `<color=#ff0000>Warning` 这种 key 不会被标签里的 `=` 截断。
- 空行、以 `#` 开头的行跳过（`#` 只在行首算注释，key 中间的 `#ff0000` 不受影响）。
- `=` 左边或右边为空 → 整行忽略。
- 整行会先 `Trim()`，所以译文尾部空格要靠 `\t` 之类的转义来保留。

```
Fuel capacity=燃料容量
- Lowest space use=-占用空间最小
<color=#ff0000>Overheating!=<color=#ff0000>过热！
Max width\=2 m=最大宽度\=2 m
```

前两行是普通词条；第三行的 `=` 在 `<...>` 标签里，因此不算分隔符；第四行的 `\=` 才是转义过的等号
（标签**外**的裸 `=` 会被当成第一个分隔符）。

## 转义

**只有 4 种转义**：`\n`、`\r`、`\t`、`\=`。其余 `\X` 原样保留——所以 Windows 路径
`C:\Users\me\Desktop` 可以直接当 key 用，反斜杠不会被吃掉。

- `\=` 用来表示原文里本身含 `=`（见上例），它不参与分隔符扫描。
- 多行文本：游戏里的换行统一按 LF 匹配（key 里的 CRLF 会被归一化成 LF），译文里写 `\n`。

## 数字模板 `{{A}}`、`{{B}}`…

原文里的数字会被归一化成占位符，一条模板盖住一切实数值。识别的数字形如 `-?\d[\d,]*(?:\.\d+)?`
（可带负号、千分位逗号、小数）。**富文本标签原样保留**，包括标签内的数字（`<size=20>` 不会变成 `{{A}}`）。

- 占位符按 Excel 列名顺序编号：第 1 个 `{{A}}`、第 2 个 `{{B}}`……第 27 个 `{{AA}}`。
- 译文里写 `{{A}}` 就在那个位置回填原文的实际数字；**不写就等于丢掉那个数字**，想省就省。
- 匹配顺序：精确 key → 数字模板 → 旧版模板（不保护标签的那种，为兼容早期提取的词条而保留）→ 通配符。

```
{{A}} [Loader]={{A}} [装填手]
{{A}} °/s={{A}} °/s
```

## 通配符 `*`

key 里含 `*` 时，整条 key 编译成正则：`*` 匹配任意字符，**前面的 `*` 非贪心、最后一个贪心**。
译文里的 `*` 按捕获顺序依次替换回去。

```
Are you sure you want to delete the blueprint *=确定要删除蓝图 * 吗？
This blueprint was saved in v*=该蓝图由游戏版本 * 保存。
```

一个限制：**待匹配的原文里本身含 `*` 时直接跳过通配符匹配**（否则分不清哪个 `*` 是通配位）。

## 提取模式（找漏翻的原文）

配置里 `ExtractionMode = true`（且 `Enabled = true`）后，插件把没匹配上的原文追加到
`<游戏根>\Translations\_ExtractedText.txt`，数字已经替你换成 `{{A}}`：

```
# 由 SprocketTranslation（汉化：七夜已逝 / Sevenight）自动提取的未翻译原文，每行一条；"="后填上译文即可生效。数字已替换为 {{A}} 占位符（如 "燃料：{{A}}"）。
<某条没匹配上的原文，数字已换成 {{A}}>=
```

注意两点：

- 它是**待译队列**，不是词条总表。填上译文之后它就会被当成普通词条文件加载（尾部为空的行会被忽略，
  所以没填的行不影响任何东西）；建议填完后把内容整理进自己的词条文件，再把队列清回只剩那行 `#` 表头，
  否则它越写越长。
- 插件启动时会读一遍这个文件做去重，已经在里面的原文不会重复写入。

## 常见坑

- **方框字**：译文用了字体里没有的字形。面板字体由本插件统一替换（`FontFile` 配置项，
  见 `README.md`），字体缺字形就会出方框，跟词条本身无关。
- **改了没生效**：先确认这行的 `=` 是唯一分隔符、原文大小写与游戏内一致（匹配是精确的，只有数字走模板）。
- **富文本标签**：译文里该保留的 `<b>`、`<color=...>` 要照着写，插件不会替你补。
